JEWEL FASHION DESIGNER VENTURE — WEBSITE FILES

CONTENTS
- index.html : website content and sections
- style.css  : black-and-gold decorative design
- script.js  : mobile menu and WhatsApp enquiry behaviour

HOW TO OPEN IN ACODE (ANDROID)
1. Extract this ZIP in your phone's File Manager.
2. Open Acode.
3. Use Open Folder and select the extracted folder named Jewel_Fashion_Designer_Venture.
4. Open index.html and use Preview to view the website.
5. Keep all three files in the same folder. Do not rename them unless you also update the links in index.html.

WHATSAPP NUMBER — ADD LATER
1. Open script.js.
2. Find: const WHATSAPP_NUMBER = "";
3. Put the business number between the quotation marks, using country code and digits only.
   Example format for a Nigerian number: const WHATSAPP_NUMBER = "2348012345678";
4. Save the file and preview the website again.

IMAGES
The sample fashion images are loaded from Unsplash over the internet, so data connection is needed to display them. They are style inspiration; replace them with Jewel's own product photographs when available.

IMPORTANT
This is a customer-facing website starter. It does not include a secure admin dashboard yet. An admin page that can change live products needs a secure backend or content-management service; a password written only in front-end JavaScript is not secure.


FASHION PICTURES
The website now includes 15 fashion image placements across the collection cards and gallery. The image links are online Unsplash images, so an internet connection is required to display them. If an image does not load, check the internet connection.
